# Frontend del Laboratorio

SPA React/Vite del sistema de Calidad Talca. Consulte el `README.md` de la raíz
para instalación, configuración, seguridad, pruebas y despliegue.

```powershell
npm ci
npm run dev
npm test
npm run lint
npm run build
```

Durante desarrollo, Vite redirige `/api` a `http://127.0.0.1:8000`.
